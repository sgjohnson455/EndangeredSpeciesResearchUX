# EndangeredSpeciesResearchUX
Updated research project test file with react and flask working for backend

To run this project locally:

Clone this repository. To view full project, both react frontend and flask backend must be running.

To set up frontend server:
- Open terminal

Commands:
- cd frontend
- npm install
- npm run dev

Keep the terminal that you opened the frontend into open. 

To setup backend server: 
- Open another terminal (again, don't close frontend terminal!!)

Commands:
- cd server

For Windows Only, do:
- python -m venv venv
- venv\Scripts\activate
- pip install Flask

For Mac Only, do:
- python3 -m venv venv
- source venv/bin/activate
- pip3 install Flask
